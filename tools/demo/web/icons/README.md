# Demo app icons

Brand icons bundled for offline use by the web demo only; the native app
reads icons from the system icon theme on a real desktop.

- Most marks come from [Simple Icons](https://simpleicons.org) (CC0).
  `code.svg` is the VS Code logo from the
  [vscode-icons](https://github.com/vscode-icons/vscode-icons) project (MIT).
- KDE app marks (`kate.svg`, `dolphin.svg`, `systemsettings.svg`,
  `konsole.png`) are Breeze icons from the corresponding KDE projects
  (LGPL-2.1-or-later / project licenses).

All trademarks belong to their respective owners; the marks are used to
identify the user's own installed applications.
